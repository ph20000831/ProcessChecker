# 进程监测-谁在偷偷运行？
- 监测并列表化展示非系统级正在运行的进程
- 纯绿色安全不联网，唯二请求权限（1、通知 2、获取应用使用信息），可选不授予
- 极小体积，安装包不到1.2MB
- MVI架构，纯compose，只有一个页面一个弹窗
- 点击item跳转系统设置杀进程，强行停止进程后自动跳回页面，自动/手动刷新列表
- 前台服务+通知提示，可开关
- 开机自启动+后台常驻+系统级WorkManager1小时间隔轮询（自动跳过0:00-7:00 基本不耗电）
# 注意事项
- 自用app，适配的荣耀magic8+android16+arm64-v8a
- 理论上系统魔改不大的品牌使用不会有什么问题
- 安装包在Releases自取、或自行下载源码打包
